| Term | Meaning |
|---|---|
| Auditor | A read-only role: reads the values, the evidence and the history. Changes nothing |
| Campaign | The collection of a framework's KPIs for one period, for example 2026. Its statuses: in preparation, open for data entry, review, closed |
| Catalogue | The single list of all the KPIs of the installation. Several frameworks share it |
| Completion rate | The share of expected values that are validated |
| Consolidation | The calculation of a value for an organisation from the values of the organisations below it |
| Contributor | The person who enters the values of their organisations, adds the evidence and validates the entry |
| Draft | A value entered but not validated yet |
| ESRS | The European Sustainability Reporting Standards of the CSRD. {name} provides the revised ESRS as eleven templates, one for each standard, to install by material topic |
| Evidence | The file that supports a value: PDF, JPG or PNG |
| Framework | An organised list of KPIs, with themes, units and formulas, for example the Basic module of the voluntary standard VS |
| KPI | Key performance indicator: one figure collected or calculated |
| MCP server | The connection that lets an AI assistant work in {name} with the rights of the person who connects it. Off by default |
| N-1 | The same period in the previous reporting year |
| Organisation tree | Your organisations, arranged in levels. You choose the levels and their names |
| Pay transparency | The EU directive 2023/970 asks employers to report their gender pay gaps. {name} provides a template for it, entered by each employer |
| Reminder | An email that tells a person what is left to fill in or to validate |
| Space | A separate area of one installation, with its own frameworks, organisations, values and evidence, for example one per department. A person signs in once for all their spaces |
| Space manager | The person who creates the spaces and gives people access to them. Only a space manager changes the settings of the whole installation: email server, email alerts, automatic updates, copy of the backups, company sign-in |
| Template | A ready-made framework provided with {name}: the Basic and the Comprehensive module of the voluntary standard VS, pay transparency and the eleven ESRS templates |
| To be handled | The list of what needs attention: variances, unexpected values, rules between KPIs |
| Validated | The contributor confirmed that the entry is complete |
| Validator | The person who reviews the values of their organisations. Can put an entry back to draft |
| Voluntary standard VS | The European voluntary standard for sustainability reporting, formerly VSME. {name} provides it as two templates |
