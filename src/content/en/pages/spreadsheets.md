You don't have to drop Excel. You still import values from Excel or CSV. You still export tables to Excel. {name} handles what gets hard with spreadsheets when many people enter data: collecting the figures, storing the evidence, calculating the totals.

| Task | Spreadsheets and emails | {name} |
|---|---|---|
| Collect from every site | One file per site, sent by email | One campaign, data entry online, on a computer or a phone |
| Know what is left to do | A tracking sheet updated by hand | Completion rate in real time, for each organisation |
| Remind contributors | Emails written one by one | Automatic reminders, with a template that you write |
| Keep the evidence | Files in folders, searched for on the day of the audit | A file attached to each value |
| Check the figures | Formulas and checks by eye | Automatic checks and a "To be handled" list |
| Calculate the group totals | Formulas copied between files | Consolidated automatically through the organisation tree |
| Show the audit trail | Version names like "v4_FINAL" | A history for each value: who, what and when |
| Give the auditor access | Files sent on request | A read-only auditor account |

## When to keep spreadsheets

- For a one-off analysis of exported data.
- To prepare a framework before importing it: the Excel template describes your KPIs.
